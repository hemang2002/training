Chat with your own PDF, then build an AI agent

Seven small pages, one idea each. First we teach an AI to answer questions from your own PDF (RAG). Then we give it tools and a loop so it can decide what to do next (an agent). No heavy frameworks: just Python, open-source models on Groq, and live Google search with SerpAPI.

🧭 The story, in one line

🤷 LLM doesn't know my PDF→ ✂️ chunks→ 🔢 embeddings→ 🔎 search & answer→ 🛠️ tools: web search + calculator→ 🔁 agent loop

Each page answers the question the previous page left open.
