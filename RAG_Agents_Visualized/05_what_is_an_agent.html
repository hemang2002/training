What is an agent?

A chatbot answers in one shot. An agent can stop, use a tool, look at the result, and try again until it has the answer. An agent is just three things: an LLM + tools + a loop.

👋 New here? The 30-second version

🧸 Think of it like this

A new intern at a desk with a phone to Google things and a calculator. They read the task, use a tool, look at the result, decide the next step, and stop when the job is done.

👀 Notice this

The LLM never runs a tool itself. It only writes "please call this tool". Our Python code runs it and hands back the result.

📖 Words, made easy:
LLM = the AI brain that writes text (Llama 3.3 on Groq) Tool = a normal Python function the agent may useLoop = repeat until done Agent = LLM + tools + a loopSerpAPI = a service that lets our code run a Google search

① Chatbot vs agent

The question: "How old was the Eiffel Tower when the Burj Khalifa opened?"

💬 Chatbot

❓ Question→ 🧠 LLM guesses→ "Maybe 125 years?" ❓

It answers from memory only. It cannot check anything, knows nothing newer than its training, and is weak at exact maths.

🤖 Agent

❓ Question→ 🤔 Think→ 🛠️ web_search ×2→ 👀 1889 and 2010→ 🤔 Think→ 🛠️ calculator→ 👀 121→ ✅ "121 years"

More steps, but every fact comes from a live Google search and the maths comes from a real calculator.

② The agent loop

🤔 Think🧠 LLM→ 🛠️ Act🐍 our code→ 👀 Observe🐍 our code↺ back to Think
Done?→ ✅ Answer🧠 LLM
Press ▶ Next part.
question = "How old was the Eiffel Tower ...?" memory = [] # what the LLM has seen for step in range(5): # max 5 rounds reply = ask_llm(question, memory) # 🤔 Think if reply.is_final_answer: print(reply.text); break # ✅ Answer result = run_tool(reply.tool, reply.input) # 🛠️ Act memory.append(result) # 👀 Observe

No framework. Just a Python for loop, the Groq API and two tools: web_search(query) (live Google results via SerpAPI) and calculator(expression).

🧪 Try this (guess first!)

  1. Who actually runs calculator("2010 - 1889"): the LLM or our Python code?
    AnswerOur Python code. The LLM only writes the text "call calculator with 2010 - 1889". Our loop reads that, runs the function, and sends back 121.
  2. Why does the loop have a limit of 5 rounds?
    AnswerSo it can never run forever. If the LLM keeps asking for tools and never answers, we stop after 5 rounds.
  3. The chatbot was fast. Why use an agent at all?
    AnswerBecause the chatbot guessed. The agent looked the facts up on the web, live, and used a real calculator, so its answer is correct and you can check where it came from.
