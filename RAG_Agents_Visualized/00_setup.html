Setup: two free API keys

Our notebooks use two free online services. Groq runs the big language model that writes answers. SerpAPI lets our agent search Google live (pages 5–6). Each one needs a key: a long secret password that says "this request is from me".

👋 New here? The 30-second version

🧸 Think of it like this

A gym gives you a membership card. You show it at the door and they let you in. An API key is your membership card for a service. If someone copies your card, they can use your membership.

👆 Do this

  1. In ①, get both keys.
  2. In ②, pick your computer and copy the commands.
  3. Tick the checklist in ③.

👀 Notice this

Keys go in a safe place on your computer, never inside your code.

📖 Words, made easy:
LLM = a large language model, a program that writes textAPI = a way for your code to talk to another program API key = your secret password for that APIEnvironment variable = a named note your computer keeps for programs to read

① Get your two keys

🧠 Key 1: Groq (the LLM)

  1. Open console.groq.com and sign up. No credit card.
  2. Click API Keys in the left menu.
  3. Click Create API Key, name it training.
  4. Copy it now. Groq shows it only once.
gsk_AbC123...xyz (always starts with gsk_)

🔎 Key 2: SerpAPI (Google search)

  1. Open serpapi.com and sign up.
  2. Go to your Dashboard.
  3. Find Your Private API Key.
  4. Copy it. Only the agent (pages 5–6) uses it.
a1b2c3d4e5... (a long mix of letters and digits)
🔒 Never paste a key into your code or notebook, and never push it to GitHub. Bots scan GitHub for keys within minutes. If a key leaks, delete it on the website and make a new one.

② Store the keys safely, then install

    AnswerNo. Anyone with the key can use your account and your free limits. Your friend can make their own keys in a few minutes.

    Answersetx only affects new windows. Close and reopen your terminal or Jupyter / VS Code, then try again.

    AnswerNo. The PDF chat only needs Groq. The SerpAPI key is for the agent on pages 5–6.
