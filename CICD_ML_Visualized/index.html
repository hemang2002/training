CI/CD for machine learning

A CI/CD pipeline is a robot with a checklist. Every time the code, the data or the model changes, it runs the same steps in the same order. If a step fails, it stops and users keep the old model.

Words
CI = check every change automatically CD = release every good change safely CT = retrain automatically when the data changes Quality gate = the pass mark a model must reach Canary = the new model for a few users first Rollback = switch back to the old model Drift = live data stops looking like the training data

① Why do we need it?

😰 By hand

  1. "It works on my laptop." Different library versions give different answers.
  2. Nobody ran the tests. A small preprocessing change silently lowers accuracy.
  3. Which model is live? "model_final_v2_NEW.pth", trained on what?
  4. Rollback takes hours.

😌 With a pipeline

  1. Same steps every time, in a clean container.
  2. Tests and data checks run on every change.
  3. Every model has a version and a recipe.
  4. Rollback is one click.

② What is different in ML?

In normal software only the code changes. In ML three things can change, and each can break the app silently: no error, just worse answers.

💻

1. Code

Breaks when: the picture size changes from 96 to 64.

Checked by: unit tests.

📊

2. Data

Breaks when: a new camera makes photos darker, or labels are missing.

Checked by: data checks.

🧠

3. Model

Breaks when: total accuracy looks fine, but "cat" is often wrong.

Checked by: an exam with a pass mark.

🤔 Check yourself

  
    
    
  1. Why is "the tests passed" not enough to release an ML model?
      
    AnswerTests check the code. The model can still be worse because of the data. You also need data checks and a quality gate compared with the production model.
    2. 
    
  2. What four things must be recorded to rebuild a model exactly?
      
    AnswerThe code version, the data version, the settings (hyper-parameters and seed), and the environment (library versions).
    3. 
    
  3. Continuous delivery vs continuous deployment?
      
    AnswerDelivery: a human presses the release button. Deployment: it is released automatically when all gates pass.
