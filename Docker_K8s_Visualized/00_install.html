Install everything: one program

You install only Docker Desktop. It gives you Docker (to build and run containers), Docker Compose (to run several containers together) and a one-click Kubernetes with kubectl. No minikube, no kind, no cloud account. Tick each step when it works on your PC.

👋 What you need

💻 A PC

Windows 10/11 (64-bit) or Ubuntu 24.04+ with a desktop. At least 8 GB RAM (16 GB is comfortable) and ~15 GB free disk.

🌐 Internet

Only for the first downloads (Docker Desktop ≈ 600 MB, Python base image ≈ 50 MB, Python packages ≈ 50 MB).

🔑 Admin rights

Installing needs administrator (Windows) or sudo (Linux) once. After that, everything runs as your normal user.

1 · Download and install Docker Desktop

  1. Open https://www.docker.com/products/docker-desktop/ → Download for Windows.
  2. Run Docker Desktop Installer.exe. Keep "Use WSL 2 instead of Hyper-V" ticked → OK.
  3. When it says Close and restart, restart the PC.
  4. Open Docker Desktop from the Start menu, accept the terms (you can skip signing in).
  5. Wait until the bottom-left corner shows "Engine running".

If Docker asks you to update WSL, press the button it shows, then open Docker Desktop again.

1a · Check that your PC can run virtual machines (KVM)

ls -al /dev/kvm
crw-rw----+ 1 root kvm 10, 232 … /dev/kvm
sudo usermod -aG kvm $USER

If /dev/kvm doesn't exist, switch on virtualization (VT-x / AMD-V) in the BIOS. After usermod, log out and log in again.

1b · Add Docker's package source

sudo apt update && sudo apt install -y ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo $VERSION_CODENAME) stable" | sudo tee /etc/apt/sources.list.d/docker.list
sudo apt update

1c · Download and install Docker Desktop

curl -LO https://desktop.docker.com/linux/main/amd64/docker-desktop-amd64.deb
sudo apt install -y ./docker-desktop-amd64.deb
# a line "Download is performed unsandboxed as root…" at the end is normal

Then open Docker Desktop from the applications menu, accept the terms, and wait for "Engine running".

2 · Check Docker works

Open a new terminal (Windows: PowerShell · Linux: Terminal) and run:

Real output
docker --version
Docker version 29.8.0, build 88096ef
docker compose version
Docker Compose version v5.5.1
docker run --rm hello-world
Unable to find image 'hello-world:latest' locally
latest: Pulling from library/hello-world
4f55086f7dd0: Pull complete
Status: Downloaded newer image for hello-world:latest

Hello from Docker!
This message shows that your installation appears to be working correctly.

To generate this message, Docker took the following steps:
 1. The Docker client contacted the Docker daemon.
 2. The Docker daemon pulled the "hello-world" image from the Docker Hub.
 3. The Docker daemon created a new container from that image which runs the
    executable that produces the output you are currently reading.
 4. The Docker daemon streamed that output to the Docker client, which sent it
    to your terminal.

Your version numbers may be newer. That's fine. "Hello from Docker!" is what matters, and those four steps are the whole of Docker in a nutshell (page 1).

3 · Switch on Kubernetes (same clicks on Windows and Linux)

  1. Docker Desktop → left menu Kubernetes → Create cluster (older versions: ⚙️ Settings → Kubernetes → Enable Kubernetes → Apply).
  2. Choose Kubeadm (a single node: the simplest, and it can use the images you build yourself) → Create.
  3. Wait 1–3 minutes until it shows Kubernetes running in green.

🐧 Linux only: install kubectl once (Windows already has it):

curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
sudo install -o root -g root -m 0755 kubectl /usr/local/bin/kubectl

4 · Check Kubernetes works

Real output
kubectl version --client
Client Version: v1.36.1
Kustomize Version: v5.8.1
kubectl config use-context docker-desktop
Switched to context "docker-desktop".
kubectl get nodes
NAME             STATUS   ROLES           AGE   VERSION
docker-desktop   Ready    control-plane   19h   v1.36.1

One node called docker-desktop with STATUS Ready: your PC is now a (tiny) Kubernetes cluster.

5 · Get the course files

Open a terminal in the course folder (the one that contains Day4_Docker_Kubernetes_Cloud): Windows: open the folder in File Explorer → click the address bar → type powershell → Enter. Linux: right-click in the folder → Open in Terminal.

cd Day4_Docker_Kubernetes_Cloud/ml-app
docker compose up --build
# first time: a few minutes. Wait for these two lines:
api-1  | [INFO] Listening at: http://0.0.0.0:5000
ui-1   |   You can now view your Streamlit app in your browser.

Open http://localhost:8501, pick a sample picture, and the model answers. Stop with Ctrl + C. You're ready for the lab (page 12).

🧯 If something goes wrong

What you seeWhat it meansWhat to do
'docker' is not recognized / command not foundNot installed, or the terminal was opened before installingInstall (step 1), then open a new terminal
failed to connect to the docker API / Cannot connect to the Docker daemonDocker Desktop is not runningOpen it and wait for "Engine running"
Linux: Docker Desktop won't start, mentions KVMVirtualization off, or you didn't log out/in after usermodTurn on VT-x/AMD-V in the BIOS; log out and in
port is already allocatedAnother program uses port 5000, 8501 or 30080 (often the Day-3 API still running)Stop it (Ctrl + C in its terminal) or docker ps to find it
kubectl: connection refused or EOFKubernetes isn't running, or kubectl points at an old clusterkubectl config use-context docker-desktop; check Kubernetes is green in Docker Desktop
x509: certificate signed by unknown authorityYour ~/.kube/config belongs to an older copy of the clusterDocker Desktop → Kubernetes → Reset cluster (or restart Docker Desktop), then kubectl get nodes again
TLS handshake timeout now and thenThe PC is short of memory: too many containers runningStop containers you don't need (docker ps, docker stop <name>); give Docker more memory in Settings → Resources
