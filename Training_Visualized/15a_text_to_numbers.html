Text → numbers

A neural network can only do maths. So before any model can read a message, every word must become numbers. There are five ways to do it. Only the last one keeps the meaning.

👋 New here? The 30-second version

🧸 Think of it like this

Give every word a home on a map. Words that mean similar things live in the same neighbourhood: cat next to kitten, king next to queen. The address of a word (a short list of numbers) is its embedding.

👆 Do this

  1. In ①, compare cat with car and then with kitten.
  2. In ②, type a sentence and press Enter. Watch it turn into numbers in five ways.
  3. In ③, click words on the map, then try king − man + woman.

👀 Notice this

Letters and word numbers keep the spelling but lose the meaning. Embeddings are the first numbers where close numbers = close meaning. Every modern text model (spam filter, chatbot, search) starts with this step.

📖 Hard words, made easy:
Vector = a list of numbers, e.g. [0.2, −0.7, 0.9]Token = one piece of text, here one word Vocabulary = the list of all words the model knows, each with its own number<unk> = "unknown": the number for any word not in the list One-hot = a long row of 0s with a single 1Embedding = a short list of numbers for each word, learned so that similar words get similar lists Similarity = how much two vectors point the same way (100% = same direction)

① A computer does not read. It stores numbers.

② The text-to-numbers machine

Type a sentence and press Enter. You get the same sentence in five kinds of numbers, from the most basic to the best.

1

Letter codes

✍️ The ink. What the computer actually stores: a code number for every letter.
✗ Spelling, not meaning: cat looks like car.
2

Word IDs

🏷️ A name tag. Every word in the vocabulary gets a number, like a page in a dictionary. Unknown words get 1, empty seats get 0.
✗ The numbers mean nothing: is word 40 "half of" word 80? No.
3

One-hot

💡 A row of light switches, one per vocabulary word. Exactly one switch is on.
✗ Huge and empty. And every word is equally far from every other word: cat is as far from kitten as from pizza.
4

Bag of words

🛍️ A shopping list. Count how many times each word appears in the whole sentence.
✗ The order is lost: "dog bites man" = "man bites dog".
5

Embedding

🗺️ A place on a map of meaning. Each word gets a short list of numbers, and similar words get similar lists.
✓ Small, every number is used, and close numbers mean close meaning. This is what every modern text model uses.
👀 Read the five rows from top to bottom. Each one fixes the problem of the row above it. Only row 5 shows king and queen with almost the same colours. That is the meaning, now in numbers.

🎓 Detailed: TF-IDF, a smarter bag

A bag of words where each count is multiplied by how rare the word is across all documents: tfidf = count × log(N / docs_with_word). Little words like the get almost 0, rare words like prize get a big weight. It is still a bag, so the order is still lost. TF-IDF with logistic regression is a strong, cheap baseline for spam.

🎓 Detailed: what ChatGPT really uses

Real models do not use whole words. They use sub-word tokens (BPE / WordPiece): unhappiness → un · happi · ness. That way there is almost never an <unk>, and the vocabulary stays near 50,000 tokens (GPT-2: 50,257). Then each token ID goes through an embedding table, exactly like row 5.

🧪 Honest note: a real model's embedding has 300 to 3,000 numbers, and nobody gives them names. We built a tiny hand-made model with 14 numbers and named 12 of them (🐾 animal, 👑 royal, ♀ female…) so you can read them. Then we flattened the 14 numbers to 2 so they fit on a screen. Real models find the same kind of map on their own, from millions of sentences.

Similarity = cosine similarity in all 14 dimensions: cos(a,b) = a·b / (|a|·|b|). In word maths we skip the three input words when we search for the nearest one; that is the standard trick (word2vec does it too), because king − man + woman is often still closest to king itself. The map uses a fixed linear projection from 14 numbers to 2, then nudges overlapping labels apart a little, so map distances are only roughly right. Trust the similarity numbers.

④ Who decides where a word lives?

Nobody does. The model learns it from text. The rule: a word is known by the company it keeps. Words that fit in the same sentences get pushed close together.

🔗 In Notebook 07

The spam model's first layer is an embedding table: one row of 32 numbers for every word in the vocabulary. They start random. During training, words that help to spot spam (free, win, £, call) slowly move to the same corner.

# word IDs (row 2)  →  embeddings (row 5)
emb = nn.Embedding(len(vocab), 32, padding_idx=0)
ids = torch.tensor([[0, 0, 57, 12, 3]])  # 0 = <pad>
emb(ids).shape   # (1, 5, 32): 32 numbers per word

An embedding layer is the same as multiplying a one-hot vector (row 3) by a weight matrix, just much faster: it picks one row. So row 3 and row 5 are connected: one_hot @ W == W[id].

🎯 Challenges: guess first, then try

  1. In ②, type dog bites man, then man bites dog. Which of the five rows change, and which one stays exactly the same?
    AnswerRows 1, 2, 3 and 5 change, because they keep one entry per word, in order. Row 4 (bag of words) is identical: same words, same counts. That is why Lesson 15 needs a model that reads in order.
  2. Type a giraffe ate my homework. What word ID do giraffe, ate and homework get, and why?
    AnswerAll three get 1 = <unk>: they are not in our mini vocabulary, so the model cannot tell them apart. Real models fix this with a bigger vocabulary and sub-word tokens (switch to Detailed view in ②).
  3. On the map, click kitten. Which word is its closest neighbour: cat or puppy? Can you explain why?
    Answerpuppy comes first (91%), then cat (87%). Look at the coloured numbers: kitten and puppy both have 🐾 animal and 🍼 young switched on. "Similar" depends on which numbers match.
  4. Try paris − france + japan. What do you get? Now set the last word to india. What happens?
    AnswerThe first gives tokyo. With india it gives delhi, with mumbai a close second: the "capital of" step is a direction on the map, just like "royal".
