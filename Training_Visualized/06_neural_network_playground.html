Neural network playground

One neuron can only draw a straight line. Stack neurons in layers and the network can draw curves, circles and spirals. Build a network, press play, and watch every neuron learn its own little piece of the picture.

👋 New here? The 30-second version

🧸 Think of it like this

One neuron is like one ruler: it can only draw a straight line. Put many neurons together and they can draw any shape, the same way you can draw a circle using many short straight lines.

👆 Do this

  1. Press ▶ Train. Watch the background turn into a blue blob around the blue dots.
  2. Look at the small squares in the middle. Each one is a neuron, and each draws a simple edge.
  3. Now click Spiral and train again. It's much harder!

👀 Notice this

Test acc = how well it does on dots it has never seen. If test accuracy is high, the network really learned the shape (it didn't just memorise).

🧠 How to read this page

Left: the inputs

Each dot has a position (X₁, X₂). You can also feed the network engineered features such as X₁² or sin(X₁). Choosing good inputs is called feature engineering. Deep learning's big promise is that hidden layers can learn such features by themselves.

Middle: the neurons

Each small square shows what one neuron outputs for every point of the plane. First-layer neurons can only draw straight edges. Later layers combine those edges into curved shapes. Watch the squares change while training runs.

Right: the result

Background = the network's prediction (blue = class 1, orange = class 0). Filled dots are training data (the network learns from them). Ringed dots are test data: never used for training, only to check if the network generalizes.

🧪 Challenges (predict first, then train!)

  1. Warm-up. Default settings (Circle, 2 hidden layers of 4 and 2, tanh, Adam 0.03). Press Train. Roughly how many epochs until test accuracy reaches 100%?
    AnswerAbout 25 epochs. Look at the neuron squares: the first-layer neurons draw straight edges, and the later layers combine them into a closed "blob" around the centre.
  2. The XOR puzzle. Choose XOR and remove all hidden layers (press − until 0). Train. Then switch on the X₁·X₂ feature.
    AnswerWith only X₁ and X₂ and no hidden layer, the model is a single straight line. No line can separate XOR (opposite corners share a colour), so the loss stays at 0.69, which is guessing level. (Accuracy may still show about 70%: the best any straight line can do is get 3 of the 4 corners right.) X₁·X₂ is positive in the blue corners and negative in the orange ones, so with that feature one "line" solves it (100%). This exact problem (Minsky & Papert, 1969) is famous for stalling neural-network research for years.
  3. Features vs layers. Circle, 0 hidden layers, only X₁ and X₂: train. Now switch X₁, X₂ off and X₁², X₂² on.
    AnswerWith X₁ and X₂ it fails (about 0.69 loss). With X₁² + X₂² it reaches 100%, because X₁² + X₂² is the squared distance from the centre, and a threshold on it is a circle. A good feature can replace a whole hidden layer. Hidden layers are how the network learns such features when we don't know them.
  4. How many neurons? Circle, one hidden layer. Try 2 neurons, then 3, then 4. For each, press 🎲 New weights and train 200 epochs, at least 6 times. Count your successes.
    Answer2 neurons: never. Two straight edges can only make a band or a wedge, so it gets stuck around 80% every time. 3 neurons: sometimes. Three edges can make a triangle around the centre (≈ 100%), but in our test only 6 of 10 random starts found it (the first four tries all got stuck at ≈ 80%). 4 neurons: every try succeeded. A bit of extra capacity makes training far more reliable, not just more accurate. Where you start matters, which is why results vary between random seeds.
  5. Why activations? Circle, 3 hidden layers of 8 neurons, activation linear. Train.
    AnswerIt fails, just like 0 hidden layers. A stack of linear layers is still one linear function (a line), no matter how deep. The nonlinear activation (tanh, ReLU) is what gives depth its power. Lesson 5 shows this bend up close.
  6. The spiral boss. Spiral, 3 hidden layers of 8, tanh. Train about 300 epochs. Then switch the activation to ReLU and train again (try 2–3 New weights). Finally switch back to tanh and add sin(X₁) and sin(X₂).
    Answertanh struggles: roughly 75–88% on training data and only 60–70% on test data after 300–500 epochs. ReLU can do much better (95%+ test on good tries by epoch ~300), but it is fickle: some starts get stuck around 75%, and a good run can suddenly get worse again (watch the loss curve jump). With the sin features the problem becomes easy: 94–100% on training data within 25 epochs, and 85–98% on test data. Hard problems need the right mix of architecture, activation and inputs, and trying them out is the job.
  7. Memorising instead of learning. Circle, noise 50, training data 10%, 4 hidden layers of 8. Train about 1000 epochs. Watch train vs test loss. Then set L2 = 0.01 and retrain (New weights). Then try L2 = 0.03.
    AnswerWithout L2: training loss drops to ≈ 0 (100% train accuracy) but test loss climbs above 2 (≈ 73% test accuracy). The network memorised 30 noisy points, including their noise: overfitting. With L2 0.01: test loss stays around 0.7 and test accuracy improves (≈ 76%). With L2 0.03 the penalty is so strong that the weights collapse to zero and the network predicts nothing useful (50%). That is underfitting. Regularisation is a dial: too little overfits, too much underfits. More on this in Lesson 7, and Dropout (another brake) in Lesson 8.
  8. Too fast. Default circle, Adam with learning rate 1.
    AnswerThe picture flickers and accuracy hovers around 50%. Every step overshoots (Lesson 2). With 0.03 it learns in about 25 epochs.
  9. Vanishing gradients. Circle, 6 hidden layers of 8, activation sigmoid, optimizer SGD, lr 0.3. Train 300 epochs. Then switch the activation to tanh.
    AnswerSigmoid: nothing happens (loss stuck at 0.69). Sigmoid's slope is at most 0.25, and the chain rule multiplies one such factor per layer, so the blame reaching the first layers is tiny (Lesson 3). tanh (slope up to 1) learns the circle within about 25 epochs with the same settings. This is why deep networks switched to ReLU-like activations, and later added BatchNorm and residual connections.

🐍 The default network in PyTorch

import torch.nn as nn

model = nn.Sequential(
    nn.Linear(2, 4), nn.Tanh(),     # hidden layer 1: 4 neurons
    nn.Linear(4, 2), nn.Tanh(),     # hidden layer 2: 2 neurons
    nn.Linear(2, 1),                # output: one score (BCEWithLogitsLoss adds the sigmoid)
)
optimizer = torch.optim.Adam(model.parameters(), lr=0.03, weight_decay=0.0)   # weight_decay ≈ L2

Parameters: (2×4 + 4) + (4×2 + 2) + (2×1 + 1) = 25. The counter under the network shows this number for whatever you build. This playground's engine implements exactly the same forward and backward pass as PyTorch (checked against finite differences). One detail: here L2 is added to the weights only, not to the biases.

🤔 Check yourself

  1. Why do we need a separate test set at all? Isn't training accuracy enough?
    AnswerChallenge 7 shows 100% training accuracy with only ≈ 73% on test data. Training accuracy measures memory; test accuracy measures what we actually want: performance on new data.
  2. A bigger network always does better. True or false?
    AnswerFalse. Bigger networks can fit more complex shapes, but they also overfit small, noisy datasets more easily, and they cost more to run. (That cost is Day 2's topic: quantization and pruning.)
  3. What is the role of the activation function, in one sentence?
    AnswerIt bends the straight-line output of each neuron, so that stacked layers can build curved decision boundaries.
