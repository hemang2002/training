📏 How is it trained?

Like a classifier, but once per pixel: cross-entropy of every pixel (Lesson 5), averaged over all pixels. A 128 × 128 picture = 16,384 small classification problems at once. The encoder is a normal classification CNN, so a pretrained backbone (MobileNetV3, ResNet) can be reused and only the decoder taught.

🎓 The Dice loss

If people cover only 5% of the pixels, plain cross-entropy is mostly about background. Dice looks at the overlap directly:

Dice = 2·|P ∩ T| / (|P| + |T|) Dice loss = 1 − Dice

Often loss = CE + Dice loss. Real U-Nets: two 3×3 conv + BatchNorm + ReLU per block, max-pool to go down, transposed conv or bilinear upsampling to go up, torch.cat for the skips. DeepLabV3 and LR-ASPP are lighter "encoder + small decoder" designs.

IoU = TP ÷ (TP + FP + FN) Dice = 2·TP ÷ (2·TP + FP + FN) Pixel accuracy = (TP + TN) ÷ all pixels Pixel accuracy counts the easy background too. People are ≈ 5% of this picture, so "no person anywhere" still scores ≈ 95%. Rules of thumb: IoU < 0.5 poor, 0.5–0.75 okay, > 0.75 good, > 0.9 excellent. Dice is always a bit higher than IoU.

🐍 The same thing in PyTorch (Notebook 06)

import torch, torch.nn as nn
from torchvision.models.segmentation import lraspp_mobilenet_v3_large, LRASPP_MobileNet_V3_Large_Weights

weights = LRASPP_MobileNet_V3_Large_Weights.DEFAULT                 # pretrained on COCO, 21 VOC classes
model = lraspp_mobilenet_v3_large(weights=weights)
model.eval()                              # inference mode
out = model(x)['out']                  # [B, 21, H, W]: a score per class, per pixel
mask = out.argmax(dim=1)               # [B, H, W]: class id per pixel (15 = person)

# fine-tune: new 2-class head (0 = background, 1 = person)
model.classifier.low_classifier  = nn.Conv2d(40,  2, kernel_size=1)
model.classifier.high_classifier = nn.Conv2d(128, 2, kernel_size=1)
loss_fn = nn.CrossEntropyLoss()           # works per pixel: logits [B,2,H,W], target [B,H,W] (long)
opt = torch.optim.Adam(model.parameters(), lr=3e-4)   # small learning rate (Lesson 11)

def iou(pred, true, cls=1):
    p, t = pred == cls, true == cls
    return (p & t).sum() / (p | t).sum().clamp(min=1)

A U-Net decoder step: x = up(x); x = torch.cat([x, skip], dim=1); x = conv_block(x). The cat is the skip connection. Augmentation: use torchvision.transforms.v2 with the image and a tv_tensors.Mask together, so flips and crops hit both.

🤔 Quick quiz

  1. 🚫 "No person anywhere" scores 95% pixel accuracy. Good model?
    AnswerNo. 📏 IoU = 0: it found nobody. That's why we use IoU.
  2. You flip a photo but forget to flip its mask. What happens?
    AnswerThe answers are wrong: the model is taught that road is a person.
  3. To count people in a crowd: 🎨 semantic or 🧩 instance?
    Answer🧩 Instance: each person gets their own mask, so you can count them.
