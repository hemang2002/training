The bend: activation functions & softmax

Every neuron does two things. ① It adds up inputs × weights, which always gives a straight line. ② It pushes that number through a small bend, the activation function. Without the bend, 100 layers can draw nothing but a straight line. At the very end of a classifier, one more special function, softmax, turns the raw scores into probabilities.

👋 New here? The 30-second version

🧸 Think of it like this

A drinking straw is straight. Bend it once and you get a corner. Bend it many times and you can make almost any shape. Each neuron adds one bend. Many neurons together can follow any curve.

👆 Do this

  1. In ①, click each activation and drag z. Watch the output and the slope.
  2. In ②, press ▶ Fit with linear, then with ReLU. Straight line vs. a curve.
  3. In ④, drag the class scores and watch the probabilities. They always add up to 100%.

👀 Notice this

More neurons = more bends = a better fit of the curve. And softmax always gives the biggest probability to the biggest score. It never changes the ranking; it only says how sure the model is.

① Meet the bends

The neuron first computes z = w₁x₁ + w₂x₂ + … + b. The activation f then decides what comes out: a = f(z). The slope of f matters just as much as its shape: during backprop the blame is multiplied by this slope (Lesson 3).

👀 With ReLU every piece is a "hockey stick" with one corner (black dots on the curve). Adding sticks gives a curve made of straight bits. With tanh/sigmoid each piece is a soft S-step. With linear every piece is a straight line, and a sum of straight lines is still one straight line.

③ Deep networks: does the blame survive the trip back?

In backprop the blame is multiplied by the activation's slope once per layer. Sigmoid's slope is never more than 0.25, so after 10 layers the blame can shrink by 0.25¹⁰ ≈ one millionth. The first layers then learn almost nothing: the vanishing gradient.

④ The last layer: softmax turns scores into probabilities

Our Day-1 FashionMNIST model ends with Linear(128, 10): 10 raw scores (logits), one per class, like 2.8 or −1.3. They are not probabilities: they can be negative and don't add up to anything. Softmax fixes that: take escore for every class, then divide by the total. Big scores win big, and everything adds up to 100%.

Why "stacked linear layers = one linear layer": W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂), which is again just "matrix × x + vector". Softmax with 2 classes is exactly the sigmoid of the score difference: ea/(ea + eb) = σ(a − b). That's why a yes/no model needs only one output (Lesson 6). Adding the same number to every score changes nothing, because it multiplies top and bottom by the same ec. Real code subtracts the largest score first so that ez never overflows.

🧪 Try this (guess first, then check!)

  1. The flat ends. In ①, set z = 5 and click through sigmoid, tanh and ReLU. Which slope is almost 0? What does that mean for learning?
    AnswerSigmoid: slope 0.0066. tanh: 0.0002. ReLU: exactly 1. A neuron whose sum z is far out on a flat end is saturated: its slope is almost 0, so backprop passes almost no blame through it and its weights barely move. ReLU never saturates on the positive side.
  2. The dead zone. Still in ①, set z = −2 and compare ReLU with Leaky ReLU.
    AnswerReLU: output 0 and slope 0. If a neuron's z is negative for every input, it can never recover. That's a "dead ReLU". Leaky ReLU keeps a small slope (0.1 here), so some blame still gets through and the neuron can come back to life.
  3. No bend, no curve. In ②, choose linear and 12 neurons on the Wave. Press Fit. Then switch to ReLU (keep 12) and fit again.
    AnswerLinear: the result is a straight line (error ≈ 0.48) even with 12 neurons and 37 parameters. The sum of 12 straight lines is one straight line. ReLU with 12 neurons follows the wave closely (error ≈ 0.002, about 250× smaller). Same number of weights; the only difference is the bend.
  4. How many bends does a V need? V-shape, ReLU. Try 1 neuron, then 2.
    Answer1 neuron: one hockey stick, only one side of the V (error ≈ 0.53). 2 neurons: perfect (error 0.0000), because |x| = ReLU(x) + ReLU(−x). One corner needs one ReLU neuron.
  5. Smooth vs sharp bends. Wave with 2 neurons: ReLU, then tanh. Then the Step target with 1 neuron: ReLU vs sigmoid.
    AnswerWave, 2 neurons: ReLU makes a stiff zig-zag (error ≈ 0.21) while tanh is already very close (≈ 0.002), because S-shaped pieces match the wave's rounded humps. Step, 1 neuron: ReLU can only make a ramp that goes on rising (≈ 0.22), while one sigmoid is a soft step (≈ 0.006). Different bends suit different shapes, but with enough neurons all of them can fit anything.
  6. The vanishing gradient. In ③, keep 10 layers and click sigmoid, tanh, ReLU. How much of the last layer's blame reaches layer 1?
    AnswerSigmoid: about one millionth of the blame (1 / 1,000,000): the bars fall like a staircase, roughly 4× per layer. tanh and ReLU: about half. The blame survives. Now try 20 layers: sigmoid drops to about 1 / 700,000,000,000, so the first layers of a deep sigmoid network are practically frozen, while tanh and ReLU stay within about 3×. That's why hidden layers use ReLU-like activations (and later BatchNorm, Lesson 8), and sigmoid is kept for the output.
  7. The untrained model. In ④, press 🎲 Untrained. What are the probabilities and the loss?
    AnswerAll scores 0 → each class 10%, and the loss is −ln(0.1) = 2.303, which is ln 10. That's exactly the loss a 10-class model prints before it has learned anything. If your Day-1 loss is stuck at ≈ 2.30, the model is still guessing.
  8. Only differences count. Press ❌ Sure and wrong. Note the probabilities. Now press ➕ three times.
    AnswerAll scores go up by 3, but the probabilities and the loss don't change at all. Softmax only cares about how far apart the scores are, not how high they are.
  9. Confident mistakes hurt. Compare the loss for ✅ Sure and right, 🤔 Unsure, and ❌ Sure and wrong (the true class is shown in green).
    AnswerSure and right: ≈ 0.01. Unsure (true class Shirt at ≈ 39%): ≈ 0.94. Sure and wrong (Shirt at 0.25%): ≈ 6.0. Cross-entropy is gentle when the model is unsure, and brutal when it is sure and wrong. That pushes the model to be honest about its confidence.
  10. Temperature (Detailed). Press 🤔 Unsure and move T from 1 to 4, then down to 0.25. Does the prediction ever change?
    AnswerAt T = 1: Shirt ≈ 39%, T-shirt ≈ 32%. At T = 4 the bars flatten (Shirt ≈ 18%, T-shirt ≈ 17%); at T = 0.25 Shirt gets ≈ 68%. The ranking never changes: temperature only changes how sure the model sounds. Knowledge distillation (Lesson 12) uses T > 1 on purpose: the soft probabilities show the student that a Shirt looks a bit like a T-shirt, and not at all like a Bag.

🐍 The same thing in PyTorch

import torch, torch.nn as nn, torch.nn.functional as F

model = nn.Sequential(
    nn.Linear(784, 128), nn.ReLU(),        # hidden layer: sum, then the bend
    nn.Linear(128, 10),                # output: 10 raw scores (logits), NO softmax here
)
loss_fn = nn.CrossEntropyLoss()            # = log_softmax + pick the true class, done in one stable step

logits = model(x)                          # shape [batch, 10]
loss = loss_fn(logits, y)                  # give it the LOGITS, not probabilities

# at prediction time (Day 3 API does exactly this, in NumPy):
probs = F.softmax(logits, dim=1)           # probabilities that add up to 1
pred  = probs.argmax(dim=1)                # same answer as logits.argmax(dim=1)

Classic bug: adding nn.Softmax() at the end of the model and using CrossEntropyLoss. Softmax is then applied twice, the scores get squashed and training becomes slow. For yes/no problems use one output + BCEWithLogitsLoss (it adds the sigmoid for you).

🤔 Check yourself

  1. Why can't the hidden layers use a linear activation?
    AnswerA stack of linear layers is still one linear function. The network could only ever draw a straight line (or a flat plane), no matter how many layers it has (challenge 3).
  2. The model says Cat 50%, Dog 30%, Car 20%. The picture is a dog. What is the loss? What if it said Dog 90%?
    Answer−ln(0.3) ≈ 1.20. With Dog at 90%: −ln(0.9) ≈ 0.105. The loss only looks at the probability of the correct class.
  3. Why do CNNs use ReLU in the hidden layers but sigmoid at the output of a yes/no model?
    AnswerHidden layers need a slope that doesn't shrink the blame (ReLU: slope 1). The output needs a number between 0 and 1 that we can read as a probability (sigmoid).
  4. Your API returns "T-shirt, 99.8%" for a photo that is clearly a shirt. Is the model broken?
    AnswerNot necessarily: softmax always sums to 100%, even for pictures the model has never seen anything like. A high number means "sure", not "right". Checking how often high-confidence answers are actually correct (calibration) is part of evaluating a model (Lesson 9).
