See a neural network learn

Eight small, hands-on pages that show how training really works, one step at a time. Move the sliders, press the buttons, break things on purpose, and watch what happens.

🔁 All of machine-learning training in one loop

1 · 📦 Take some examples

Pick a few examples from the data, for example 8 photos with their correct labels. This small group is called a batch.

Lesson 4

2 · 🤔 The model guesses

The model uses its current weights (knobs) to make a guess for each example. At the start the knobs are random, so the guesses are bad.

Lessons 1 and 5

3 · 📏 Measure the mistake

Compare the guesses with the correct answers and squeeze all mistakes into one number: the loss. Smaller loss = better model.

Lesson 1

4 · 🔍 Find who is to blame

Backpropagation works out, for every single knob, which way it should turn to make the loss smaller, and by how much.

Lesson 3

5 · 🔧 Turn the knobs a little

Gradient descent turns every knob a small step in the right direction. Then we go back to step 1 with new examples, thousands of times.

Lesson 2

🧭 How to use these pages

1 · Open

Double-click any .html file. Chrome or Edge work best. No internet and no installation are needed.

2 · Start at the top

Every page begins with a "New here?" box: a simple story, three things to click, and what to look for.

3 · Guess, then check

Each page has challenges. Guess the answer first, then try it, then open the answer. Guessing is where the learning happens.

The Simple view button (top right) hides code and extra details. Switch to Detailed view to see the PyTorch code and the deeper sections.

📖 Words you will meet

WordIn plain wordsLesson
ModelA guessing rule with many knobs.1
Weight / parameterOne knob inside the model. Training changes only these.1
LossOne number that says how wrong the model is. Lower is better.1
GradientThe slope: which way to turn a knob to make the loss go down, and how strongly.2, 3
Learning rateHow big each knob-turning step is.2
BackpropagationThe trick that finds the gradient of every knob in one backward sweep.3
Batch / epochA few examples used for one step / one full trip through all the data.4
Neuron / layer / activationA tiny calculator / a column of them / the bend that lets them draw curves.5
OverfittingMemorising the practice data instead of learning the pattern.6
Kernel / convolutionA small pattern slid over an image to find where that pattern appears.7
Quantization / pruningRounding the weights to fewer values / deleting the smallest weights.8
