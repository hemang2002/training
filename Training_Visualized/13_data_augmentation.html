  • Validation / test: only resize + normalise, so the score is measured on real pictures and is the same every run.

🐍 Train and test pipelines in PyTorch

  
from torchvision import datasets, transforms
mean, std = (0.4914, 0.4822, 0.4465), (0.2470, 0.2435, 0.2616)   # CIFAR-10

train_tf = transforms.Compose([
    transforms.RandomCrop(32, padding=4),          # shift by up to 4 pixels
    transforms.RandomHorizontalFlip(),
    transforms.ColorJitter(0.2, 0.2, 0.2),
    transforms.ToTensor(),
    transforms.Normalize(mean, std),
])
test_tf = transforms.Compose([                        # NO random changes here
    transforms.ToTensor(),
    transforms.Normalize(mean, std),
])
train_ds = datasets.CIFAR10("data", train=True,  transform=train_tf)   # still 50,000 files
test_ds  = datasets.CIFAR10("data", train=False, transform=test_tf)
# train_tf runs inside __getitem__, so every epoch draws new random versions

  
🔮 Test-time augmentation (TTA)

  
For the final prediction only: predict on the picture and a few gentle versions (e.g. flipped), then average. A little more accuracy, several forward passes per picture.

  
probs = (model(x).softmax(1) + model(x.flip(3)).softmax(1)) / 2   # original + horizontal flip

  
Later: AutoAugment / RandAugment (a learned or random list of transforms), Mixup / CutMix (blend two pictures and their labels).
  In RandomResizedCrop(scale=(a, 1)), a is the smallest share of the area that is kept.
