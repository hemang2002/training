Reinforcement learning: learning by trial and error

In all the other lessons, we gave the model the right answers (labels). In reinforcement learning (RL) there are no answers. An agent tries things in a world, gets a reward (a treat or a punishment), and slowly learns which actions pay off. On this page a little mouse 🐭 learns to find the cheese 🧀, live, in your browser.

👋 New here? The 30-second version

🧸 Think of it like this

Training a dog. You can't tell the dog what "sit" means. It tries things; when it sits, it gets a treat 🦴. After many tries it sits more often. Or think of a new video game: nobody explains the rules, you just play, lose, and get better.

① What is reinforcement learning?

🔁 RL is a loop. The agent looks at the state ("I am here"), picks an action ("go right"), and the environment answers with a new state and a reward. Then again, and again.

🎯 The goal is not to get the biggest reward now, but the biggest total reward over the whole episode. Sometimes you must walk past small bad things (−0.1 per step) to reach the big good thing (+10 cheese).

🧠 Nobody tells the agent the right move. It only finds out afterwards if a move was good, and often much later: the cheese comes 12 moves after the first step. Working out which of those 12 moves deserves the credit is the hard part.

② Warm-up: the slot machines (explore vs exploit)

The simplest RL problem. There are 4 slot machines 🎰. Each one pays out 🪙 with a secret chance. The agent has 500 pulls. Which machine should it pull? It must try machines to learn which is good (explore), but every pull on a bad machine is a wasted pull. It also wants to pull the best one it knows (exploit).

🎲 ε-greedy is a simple rule for this: with a small chance ε (epsilon), pull a random machine. Otherwise, pull the machine with the best average so far.

❌ ε = 0: only exploit. All machines start at 0. The first machine that pays out once looks "best" forever, so the agent keeps pulling it, even if it's a bad one. It never checks the others.
✅ ε = 0.1: mostly exploit, a little explore. 9 pulls out of 10 go to the best-looking machine. 1 in 10 is a random test, so a wrong first guess gets fixed.
❌ ε = 1: only explore. Its estimates become very good, but it never uses them: every pull is random, so it only gets the average of all machines.

📏 Measured on this page (seeds 1–20, 500 pulls each, press 🏁 Race to repeat): ε = 0 spent most pulls on a worse machine in 13 of 20 runs (0.17–0.72 coins per pull: all or nothing). ε = 0.1 pulled the best machine 81% of the time (0.50–0.69 coins per pull). ε = 1 got only 0.37–0.45, the average of all machines.

③ The main demo: a mouse learns to find the cheese (Q-learning)

④ How does the table learn? The Q-learning update

After every single step the mouse knows 4 things: where it was (s), what it did (a), the reward it got (r), and where it landed (s′). Then:

  1. 🤔 Old guess"How good did I think this move was?" That's Q(s, a) in the table.
  2. 🎯 Better guess (the target)"The reward I just got, plus the best I can expect from the new cell." The future part is shrunk a bit by γ, because later rewards are less sure.
  3. 📏 The errorTarget − old guess. Positive = "better than I thought". Negative = "worse".
  4. 🔧 NudgeMove the old guess a small part (α) of the way towards the target. Not all the way: one lucky step shouldn't change everything.

💡 This is how the cheese's value travels backwards: the cell next to the cheese learns "+10 is close", then the cell before it learns "the next cell is good", and so on. It is like gradient descent (Lesson 2): a small step to make the error smaller, many, many times.

🎓 Detailed: the formula Q(s,a) ← Q(s,a) + α·[ r + γ·max Q(s′,·) − Q(s,a) ] target = r + γ·max Q(s′,·) if s′ ends the episode: target = r max Q(s′,·) = the best of the 4 Q-values in the new cell. Q-learning uses the best next move even if the agent will actually explore next: it learns about the greedy policy while it behaves randomly (it is "off-policy"). That's why ε = 1 can still fill the table (see ⑤).

⑤ When RL works, and when it goes wrong

Each preset changes one thing from the good settings. Load it, press ⏩ Train 100 five times (500 episodes), and look at the curves and the learned path. The numbers below were measured on this page: the same run for seeds 1–10, 500 episodes each. Press 🔬 to measure them again yourself.

✅ Good settings (α = 0.3, γ = 0.95, ε from 1 down to 0.02). It explores a lot at first, then uses what it learned. On all 10 seeds the learned path goes to the cheese in 12 steps (the shortest way).
❌ ε = 0, no exploring. The first prize it finds becomes its habit. It never finds out that the cheese is 2 cells away and worth 10 times more.
❌ γ = 0, short-sighted. It only cares about the next reward. Every step costs −0.1, so every normal move looks the same. The value of the cheese never travels back.
❌ Bad reward design: a coin that comes back. We add +1 for a coin (meant as a "hint"). The mouse finds a loophole: step on the coin, step off, step on again… This is called reward hacking: it does what we rewarded, not what we wanted.
➖ ε = 1 always: only exploring. Like the slot machines: it walks at random forever.
🎓 Bonus: no step penalty. Untick ⏱️ −0.1. You'd guess "it just wanders more". The measured effect is different: With −0.1 per step, every tried move soon looks worse than an untried one (still 0), so the mouse is pushed to try new things. Without it, that push is gone.

⑥ Where is RL used today?

🎮 GamesAlphaGo beat the world champion at Go in 2016. It learned partly by playing millions of games against itself. Later RL agents learned chess, StarCraft and Atari games.
🤖 RobotsWalking, grabbing objects, balancing. Usually trained in a simulator first (crashing a real robot 10,000 times is expensive), then moved to the real robot.
🛒 RecommendationsWhat video or ad to show next. The "reward" is a click or watch time, and reward hacking (clickbait!) is a real danger.
💬 Chatbots (RLHF)ChatGPT, Claude and other LLMs are first trained on text (supervised), then fine-tuned with RL from human feedback: people rate answers, a model learns those ratings, and RL pushes the LLM towards better-rated answers.
ℹ️ What about neural networks? Our table has 49 cells × 4 moves = 196 numbers. A chess board or an Atari screen has far too many states for a table. Deep Q-Networks (DQN, DeepMind, 2013 / 2015, playing Atari games from the pixels) replace the table with a neural network: pixels in, one Q-value per action out. The update idea stays the same: target = r + γ · max Q(s′). This page keeps the table so you can see every number.

🧪 Try this (guess first, then check!)

  1. Watch the value travel. Reset, set speed to the slowest, and press ▶ Play. Wait for the first 🧀. Look at the cell next to the cheese. Keep watching the next episodes.
    AnswerAfter the first 🧀, only the cell right next to it turns green (only one number was updated). Each later visit pushes the green one cell further back towards the start. Rewards travel backwards one step at a time. That's why RL needs so many episodes.
  2. The cookie trap. Load ❌ ε = 0 and train 500 episodes for seeds 1, 2, 3, 4, 5. How often does the mouse end at the cookie?
    AnswerMost of the time. With ε = 0 there is no randomness except for breaking ties. Once the 🍪 path has a value above 0, it always looks better than the unknown cells around it, so the mouse never walks the extra steps to the cheese. Exploration is the only way to find out that something better exists.
  3. How short-sighted is too short-sighted? In the good preset, set γ to 0.5 and train 500 episodes. Does it still find the cheese?
    AnswerYes. The cheese is 12 moves away, so with γ = 0.5 its value at the start is tiny (10 × 0.5¹¹ ≈ 0.005), but it's still the best number around, so the arrows still point to it. Only γ = 0 cuts the future off completely. In bigger worlds, a small γ makes far-away rewards vanish in noise.
  4. Reward hacking. Load ❌ coin and press ▶ Play at medium speed after 300 episodes. What does the mouse do? How would you fix the reward?
    AnswerIt stands next to the coin and steps on and off it until the 100 steps run out: about +90 per episode, much more than the +10 cheese. Fixes: give the coin only once per episode, make it smaller than the step cost, or remove it. Rule: reward the goal, not your idea of how to get there.
  5. Learning rate. What do you expect with α = 1 and with α = 0.05? Try both on the good preset.
    Answerα = 0.05: each update is tiny, so the value spreads very slowly and 500 episodes may not be enough. α = 1: each update jumps straight to the target. Here the world is deterministic (a move always does the same thing), so big steps are fine. In a random world (slippery floor), α = 1 would jump around with every lucky or unlucky step.

🐍 The same thing in Python

import numpy as np
Q = np.zeros((n_states, 4))            # the table: one row per cell, one column per move
alpha, gamma, eps = 0.3, 0.95, 1.0

for episode in range(500):
    s, done = env.reset(), False
    while not done:
        if np.random.rand() < eps:
            a = np.random.randint(4)        # explore: a random move
        else:
            a = Q[s].argmax()               # exploit: the best move so far
        s2, r, done = env.step(a)
        target = r if done else r + gamma * Q[s2].max()
        Q[s, a] += alpha * (target - Q[s, a])   # the Q-learning update
        s = s2
    eps = max(0.02, eps * 0.995)          # explore a bit less every episode

🤔 Check yourself

  1. What is the biggest difference between supervised learning and reinforcement learning?
    AnswerSupervised learning gets the right answer for every example. RL never gets the right answer: only a reward, often much later, and it has to collect its own data by acting.
  2. An agent uses ε = 0.1. What does it do on each step?
    AnswerWith 10% chance it takes a random action (explore). With 90% chance it takes the action with the highest Q-value (exploit).
  3. Q(s, →) = 2.0. The mouse moves →, gets r = −0.1, and the best Q-value in the new cell is 4.0. γ = 0.9, α = 0.5. What is the new Q(s, →)?
    AnswerTarget = −0.1 + 0.9 × 4.0 = 3.5. Error = 3.5 − 2.0 = 1.5. New Q = 2.0 + 0.5 × 1.5 = 2.75.
  4. A cleaning robot gets +1 for every piece of dirt it picks up. What could go wrong?
    AnswerReward hacking: it could learn to drop the dirt and pick it up again, forever (like our coin). Better: reward a clean floor, not the act of picking up.
  5. Why can't we use a Q-table to play Atari games from the screen pixels?
    AnswerThere are far too many possible screens: you'd need one row per screen, and you'd almost never see the same one twice. A neural network (DQN) guesses Q-values for screens it has never seen, the same way a CNN recognises cats it has never seen.
